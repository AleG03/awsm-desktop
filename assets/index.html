Opens the panel from anywhere. None is set until you choose one.

Following the system keeps the panel translucent. Choosing a theme gives it a solid background instead, because macOS fixes a window's appearance when it opens.

Where ⌘↵ and Open Console go. A Firefox container is always reachable on its own, whatever this says.

awsm can renew the active profile's credentials before they expire. This panel only reports what it decided; the renewing is awsm daemon enable.

Keys
↵Switch to the profile
⌘↵Open the console, without switching
⌘⇧↵Open it in a Firefox container
⌘FThe same, without reaching for ↵
⌘CCopy the account id
⌘⇧CCopy the profile name
⌘TOpen a terminal on that profile
⌘KClear the active profile
EscClear the search, then close

Right clicking a profile offers the same actions, on the row under the pointer rather than the selected one. Right clicking the profile at the top of the panel offers them for that one, plus clearing it.
